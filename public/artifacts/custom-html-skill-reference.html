The full custom-html skill, viewable two ways

A Claude Code skill that builds self-contained, single-file HTML artifacts — cheatsheets, research libraries, reference guides, audits, dashboards. Toggle between rendered markdown and raw source, or download a copy to install locally.

  • What it does: Generates single-file HTML documents in a warm earthy + teal design system with full light/dark theming, sidebar navigation, scroll-spy, search, and filtering.
  • How to invoke: say /custom-html, “make me a cheatsheet,” “create a reference guide,” or describe any custom HTML artifact you want built.
  • Two layout patterns: sidebar-only (cheatsheets, technical refs) or header + sidebar + hero (research libraries, resource collections).
  • Self-contained output: all CSS & JS inline, only Google Fonts as an external dependency — the file works offline and runs anywhere.
